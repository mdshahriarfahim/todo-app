# 📝 Interactive Todo List App

A lightweight, responsive, and easy-to-use Todo List application built using HTML, CSS, and Vanilla JavaScript.

## 🚀 Features

* **Add Tasks:** Quickly add new tasks to your daily list.
* **Delete Tasks:** Remove individual completed or unwanted tasks.
* **Clear All:** Delete all tasks at once with a single click.
* **Live Counter:** Dynamically updates the total task count as you add or remove items.
* **Keyboard Shortcut:** Press `Enter` to quickly add a task without clicking the button.
* **Responsive Layout:** Clean UI aligned properly with Flexbox for all screen sizes.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure.
* **CSS3:** Flexbox and custom styling.
* **JavaScript (ES6):** DOM manipulation and event listeners.
